# Security

The odhyp plugin installs skills and a commit hook that run shell commands on your machine, so please report security problems privately.

## Reporting

Use GitHub's private vulnerability reporting: [Report a vulnerability](https://github.com/odhyp/skills/security/advisories/new). Don't open a public discussion.

Please include:

- the plugin version (`VERSION`) and Claude Code version
- what an attacker can do, and the steps to reproduce it

## Supported versions

Only the latest release gets fixes.
